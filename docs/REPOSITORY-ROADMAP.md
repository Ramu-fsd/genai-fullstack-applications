# Repository Roadmap

This roadmap describes the intended progression of `genai-fullstack-applications`.

| Phase | Projects | Expected learning outcome |
|---|---|---|
| Foundations | 01–04 | Chat UX, streaming, prompt iteration, content generation |
| Enterprise knowledge | 05–06 | Document Q&A, retrieval concepts, knowledge access |
| Domain assistants | 07–10 | SQL safety, customer support, meeting summaries, financial narratives |
| Advanced workflows | 11–12 | Agent workflow design and enterprise banking architecture |

## Suggested future enhancements

- Add real provider adapters behind interfaces and configuration.
- Add integration tests using controlled test doubles.
- Add OpenAPI specifications and API contract tests.
- Add OIDC integration and role/tenant authorization tests.
- Add RAG ingestion, retrieval evaluation, and document-level authorization.
- Add tracing, token/cost telemetry, rate limiting, and operational dashboards.
- Add CI workflows for Java and frontend validation.

Mark each enhancement as implemented only after it has been built and tested.
